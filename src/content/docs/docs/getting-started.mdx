## Quick Start


<Steps>
1. Clone the repo

    ```sh
    git clone https://github.com/Psypher1/the-language-hub.git
    ```

2. Change the working directory

    ```bash
    cd the-language-hub
    ```

3. Install dependencies

    <Tabs syncKey="pm">
        <TabItem label="npm">
               ```bash
                npm install
                ```
        </TabItem>
        <TabItem label="pnpm">
               ```bash
                pnpm install 
                ```
        </TabItem>
    </Tabs>
 

4. Run the app

       <Tabs syncKey="pm">
        <TabItem label="npm" icon="npm">
               ```bash
                npm run dev
                ```
        </TabItem>
        <TabItem label="pnpm">
               ```bash
                pnpm dev
                ```
        </TabItem>
    </Tabs>
 

    That's All!!! Now open [localhost:3000](http://localhost:3000/) to see the app.

</Steps>
